# Smart Urban Parking Management System

A parking management system that helps drivers find and reserve available parking spaces based on location, while allowing space owners to manage their parking spots.

## Features
- User Registration and Login
- Role-Based Access (Driver, Owner, Admin)
- Parking Search and Reservations
- Parking Space Management
- Pricing and Overstay Penalties
- Check-in and Check-out

## Technologies
- PHP (Native)
- MySQL
- HTML, CSS, JavaScript
- Bootstrap

## Implementation
Backend implementation using PHP and MySQL, following MVC architecture and OOP principles. The project uses a pre-built frontend template integrated with the backend functionality.
